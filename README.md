# genderreveal

赤ちゃんの性別をサプライズで発表するウェブアプリです。

## 使い方

1. 妊婦さんにトップページのURLを渡します。
2. 妊婦さんが「男の子」か「女の子」を選ぶと、コード付きの発表用URLが作られます。
3. そのURLを家族や友だちに共有します。
4. 受け取った人はプレゼント箱を3回タップします。カウントダウンと色の点滅のあとで性別が表示されます。

性別はコードのハッシュ値で表しているので、URLを見ただけでは分かりません。
サーバーは不要で、GitHub Pages などの静的ホスティングにそのまま置けます。

## ローカルで確認

```
python3 -m http.server 8000
```
